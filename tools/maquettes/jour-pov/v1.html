Le jour en vue assise (T23, tour 1)

Ce qu'on s'est dit : au jour, la table disparaît et il ne reste que les chats en cercle. Les cartes de la table s'envolent jusqu'à l'écran (touche 1, les joueurs) et les rôles de la partie avec les deux compteurs les rejoignent (touche 2). Les deux rangées sont ouvertes d'office, empilées. On vote en cliquant un chat, et le vote se voit sur les chats. T ouvre la tablette sur le tableau, E les emotes, Tab reste. La nuit ne change pas.

Tout est rendu depuis le jeu (la scène, les chats et leur lumière, la table, les cartes) ; les chats sont figés dans une pose, et les cartes sont recomposées avec les images du jeu. Ce qui est à choisir : les mouvements, les places, les marques. Les sections 4 et 5 sont en vue relevée (K2) pour bien voir les chats.

1. Comment la table s'en va

Les cartes partent d'abord vers l'écran, puis la table s'en va. Seule la façon dont la table part change.

T1Elle s'enfonce dans le sol

La table descend sous le plancher, le liège avec elle.

T2Elle se défait

La table se dissout par plaques irrégulières, sur place (un shader de dissolution).

T3Le noir l'avale

Tout s'éteint un instant ; quand les lumières des chats reviennent, la table n'est plus là.

2. La vue une fois la table partie

Assis, la tête repose baissée vers la table (35°). Sans table, on regarde le plancher.

K1La tête reste baissée

Rien ne bouge : on voit le bas des chats en haut de l'écran, on relève la tête à la souris pour les voir.

K2La vue se relève sur les chats

Quand la table est partie, la tête se relève doucement (35° vers 20°) : les chats sont en face.

3. Les deux rangées

Appuie sur 1 ou 2 (ou touche leur signe en bas à gauche) : la rangée glisse hors de l'écran par le bas, et revient. Les flèches tournent la tête : les rangées restent en place.

R1La copie du liège

Rangée 2 = la bande du liège telle qu'elle est sur la table, les deux compteurs à droite.

R2Recomposée, serrée

Les portraits par camp sous le logo du camp, plus petits ; les cartes des joueurs plus petites aussi.

R3Grandes cartes

Les cartes des joueurs en grand (on lit tout), les rôles recomposés en dessous.

4. Le vote se voit sur les chats

Même moment partout : Steve, Brandon et Kiwi votent Uptn, Mathis vote Kiwi. Clique un chat pour voter toi aussi.

V1Un fil du chat qui vote au chat voté

Un fil rouge tendu de tête à tête ; les fils des chats hors de vue entrent par les bords.

V2Les poses d'accusation du jeu

Le chat qui vote prend la pose « Accusing », le chat voté « Accused Idle » (animations déjà faites).

V3Le voté rougit

Plus un chat a de votes, plus sa lumière tourne au rouge ; on ne voit pas qui vote.

5. Survol : le chat et sa carte

Passe sur un chat ou sur une carte de la rangée 1 : l'autre s'allume aussi. Au repos, Uptn est survolé.

H1Un contour, la carte se lève

Le chat prend un contour clair, sa carte sort de la rangée.

H2La lumière

Le spot du chat s'intensifie, sa carte s'éclaire ; pas de contour.

H3Son nom au-dessus de lui

Le pseudo s'affiche au-dessus du chat (comme sa plaque de nom), sa carte se lève.
