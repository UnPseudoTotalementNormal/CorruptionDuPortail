# Cat art references (artist's Drive, "Cats" folder)

Copied from the artist's Drive on 2026-10-13 so the intentions stay next to the code. Source art pipeline:
`tools/art/cats/README.md`.

- `Corrupted Deadlines.pdf` (+ its screenshot): the artist's 3D asset tracker. What each animation is for, as written
  there (design intent, not to be re-invented):
  - **Accusing someone**: needs revision, "clearer with some furrowed brows" → the eyes' Angry shape key while
    accusing (CatFrown).
  - **Crying**: needs revision, "need the water particles" → CatTears (the file's tear particle system).
  - **Waving**: validated.
  - **Cat chaining**: needs revision. Intended: the cat rises, flips, chains come from the sky, it returns chained;
    chained = its default pose; an emote tried while chained replays the struggle. The delivered animation is the
    earlier version (Getting Chained, Getting Chained 2, Chained Idle, Chained Struggle).
  - **Picking up the tablet**: the cat pulls its tablet out from under the table and stares at it while the player
    keeps their cursor on it, then puts it away.
  - **Blinking**: in progress, "need all types of eyes" → only the black and white eyes have a closed variant.
  - Customization (body type, colours, eyes, mouths, hoodies / accessories) and phase 2 (table, chair, timer, candle,
    power-ups) were not started at the time.

  mock-ups used as references by the artist.
- `7gp9dsa2ynq41 (1).jpg`, `simple-adorable-white-cat-sitting-side-view-outlined-….webp`: style references.
