# Bug hunt 2026-10-06 — autoplay campaign (priority: desyncs)

Goal: find what is still broken after NET-00..11, rejoin (#104/#105) and the late-joiner fix (#103), so the bugs can be
fixed in one batch, then re-checked by autoplay. Nothing here is fixed yet (except B0, committed locally).

## How it was hunted

- Network scenarios (existing + 9 new: 7 real clients with chat, heavy loss, lag, rejoin at vote / night / under lag /
  all at once / after the grace delay, watchdog breakage tests), random 5-client games, every role held by a real
  client (`sweep_client_powers.py`).
- Desync detection beyond the in-game tripwire: every replicated value (each NetworkVariable / NetworkList of every
  spawned object, ~290 values) compared host vs each client at every settled phase (`compare_replication.py`), plus,
  per player, the knowledge and icons the client applied vs the server's truth for its seat.
- Errors / stalls / input misses deduplicated over all runs (`harvest_issues.py`).

**Desync result: 0 persistent desync** in 41 network runs: ~2,300 (client, phase) comparisons of every replicated value,
plus 692 per-player comparisons of knowledge and icons (server truth vs what the client applied). One transient
`turnStats` difference (sampling-time artefact, aligned at the next phase). The only desync found and proven this
session is B0 (rejoin, fixed).

## Tool problems found (fixed in the autoplay framework, not game bugs)

- No stall detection outside the game loop, no death detection: a client crashed in the graphics driver (D3D12, 0xC0000005)
  and the host waited 15 min → package `AutoplayWatchdog` (budgets per step / phase, alerts, fail with report, operator
  extend / abort) + launcher `DIED` / abort / one run at a time. Breakage tests `watchdog-stall`, `watchdog-died`.
- `analyze_rejoin.py` ignored state-only captures and flagged a use spent just before the drop; `RejoinThroughMenu`
  hung on a refused rejoin; `real-input-tour` still expects a leaver to be chained (seat now reserved 120 s since #104).
- `Soin Baveux` (bot on the host) sometimes never reaches its role step after a fake character pick: autopilot path,
  to check.
- Speed: forced roles are seated on the requested holder (no re-roll), clients capped at 30 fps, intro / chaining
  at ×12, 2 lanes in parallel.

## Not bugs (checked)

- A chained but present player can vote: owner ruling (`VoteState.CanVote`).
- A rejoin after the grace delay is refused with "La partie a déjà commencé.", the saved session is dropped and the
  button hidden: as designed.
- Rejoin: the day counter arrives by RPC 3 frames after the phase index (journal shows `day=1` once); the client start
  is deferred until it, nothing visible.
